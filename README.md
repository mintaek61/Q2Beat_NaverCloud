<h2>✍🏻 프로젝트 개요</h2>
친구끼리 모였을 때 간단하고, 특별한 도구 없이 어디서든 즐길 수 있는 게임
다양한 퀴즈를 풀면서 경쟁심을 유발하여 재미를 줄 수 있고 지식도 습득할 수 있다.
